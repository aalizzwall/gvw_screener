# Security Policy

## Supported versions

| Version | Supported |
| --- | --- |
| `main` | Yes |

## Reporting a vulnerability

Do not report vulnerabilities in public issues.

Use GitHub's private vulnerability reporting for this repository:
https://github.com/aalizzwall/gvw_screener/security/advisories/new

Private vulnerability reporting is not currently enabled for this repository. The repository owner must enable it under **Settings → Code security and analysis → Private vulnerability reporting**, if the feature is available for this account and repository.
